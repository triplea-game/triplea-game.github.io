An improved rules implementation of "World War II Classic 2nd Edition". Contains a feature that checks for stack limits, which was missing in the original module. It is specifically designed for use in the League on axisandallies.org. Can also be used for non-league games. Based on the board game: Axis & Allies - Classic 2nd Edition (1984)
